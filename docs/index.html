🏛️ Why Litrun Exists

Engineered from the ground up for embedded Linux systems.

🖥️
Embedded Web UI Console
Run litrun ui for an instant self-hosted visual device dashboard: real-time telemetry gauges, multimodal chat playground, and 40-pin GPIO pin matrix.
🚀
Rockchip NPU Acceleration
Run litrun run --npu to offload matrix tensors to on-chip 6.0 TOPS NPUs (Orange Pi 5 / RK3588) with zero CPU overhead.
⚡
1.87ms C99 Probing
Parses devicetree and aux vectors (getauxval) directly in native C99 with zero subprocesses or Python overhead.
🛡️
Active Memory Governor
Inspects Linux memory cgroups (v1/v2) and prevents kernel OOM panics and SD card swap thrashing before allocations occur.
⏱️
Sub-50ms TTFT
Keeps model weights pinned in RAM across multi-turn chats and REST requests, eliminating subprocess reload latency.
📐
Strict GBNF JSON Schema
Guarantees deterministic, hallucination-free JSON outputs for Home Assistant, ROS 2, and robotics actuators.
🌐
Drop-In OpenAI Server
Run litrun serve --port 8080 and connect directly to LangChain, LlamaIndex, Home Assistant, and open-webui.
👁️
VLM Visual Edge Inspection
Run litrun see /dev/video0 for live V4L2 camera frame perception using SmolVLM (240MB) & Moondream2.
🎙️
Edge Audio Perception
Run litrun hear --mic --pipe-run --tools to capture microphone audio, transcribe via Whisper, and execute GPIO actions.
🤖
ROS 2 Robotics Node
Native ROS 2 Humble/Iron node publishing deterministic action payloads to /robot/action_decision and twists to /cmd_vel.
🏠
1-Click Home Assistant & GPIO
Official supervisor add-on repository with autonomous sysfs GPIO control (litrun run --tools) for fans, relays, and sensors.
📦
Precompiled Multi-Arch
Instant prebuilt binaries tuned for Cortex-A72 NEON, Cortex-A76 DotProd, and x86 AVX2—no CMake or 45-minute compiles.
🏎️
NVIDIA Jetson Hardware Acceleration
Run litrun run --gpu or --jetson to leverage 1024 Ampere CUDA tensor cores and dual NVDLA on Tegra Orin & Xavier at 28.5+ tok/s.
📚
Offline Edge Vector Search & Local RAG
Run litrun embed and litrun run --rag for embedded SQLite vector retrieval with zero cloud dependency and sub-5ms query times.
🏭
Industrial MQTT Telemetry Daemon
Run litrun mqtt --demo for autonomous real-time sensor stream anomaly reasoning and automated MQTT actuator dispatch.
📊
Automated Benchmark Matrix & JSON Reports
Run litrun benchmark --compare and --export-json for automated multi-model latency (TTFT) and token throughput telemetry across CPU, NPU, and GPU.
🐳
Multi-Arch Docker Edge Containers
Deploy anywhere in seconds with docker run -p 8080:8080 ghcr.io/assassinaj602/litrun supporting native ARM64 and AMD64 edge devices.
🌐
Edge Swarm & P2P Mesh Clustering
Form zero-config SBC clusters across Pis and Jetsons using litrun swarm beacon and capability-aware task router litrun swarm dispatch.
🧬
On-Device LoRA Adaptation
Fine-tune compact models directly on SBCs with pure Python low-rank adaptation using litrun lora init, info, and train.
⚡
In-Process C FFI Engine
Eliminate subprocess execution latency with direct ctypes linkage into native shared libraries via Model.load(..., prefer_ffi=True).
📦
Native Debian (.deb) Packaging
Run make deb to generate zero-dependency .deb packages with systemd service unit and man pages for Raspberry Pi OS & Ubuntu.
